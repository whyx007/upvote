# 名单导入 Excel 格式说明

> 模板：[名单导入模板.xlsx](名单导入模板.xlsx)。管理台「名单导入」页可直接下载，模板内含「说明」工作表。

## 支持的导入方式

### 方式 A：一张“学生”表 + 一张“教师”表

适合名单已经汇总在一个文件里：

- 「学生」表有 `班级` 列，班级写成 **七年级一班** 这种格式；
- 「教师」表有 `学科` 列；
- 表头按名称识别，不依赖列顺序。

### 方式 B：一个班一个 sheet / 一个学科一个 sheet

适合按班或按学科拆分的文件：

- 学生：sheet 名就是班级，如 `七年级一班`；sheet 内不需要再写“班级”列（写了也可以）。
- 教师：sheet 名就是学科，如 `语文`；sheet 内不需要再写“学科”列（写了也可以）。
- 可以放在一个 Excel 里，也可以一个班/一个学科一个文件分别上传。
- `汇总`、`说明` 等非班级/非学科 sheet 会被自动忽略。

### 方式 C：一个班一个文件，文件名就是班级（可鼠标多选）

适合班主任各自发一个文件：

- 文件名必须符合班级名，例如 `七年级一班.xlsx`；**系统按文件名归班**。
- 文件里 sheet 可以叫 `学生`，也可以叫 `七年级一班` 或 `Sheet1`；表头写 `学号/姓名/性别/级` 即可，`班级` 列可省略。
- 如果文件里又写了班级，且与文件名不一致，该行会报错（防止串班）。
- 管理台「一键导入 Excel 名单（可多选文件）」支持一次选择多个班级文件，逐个返回成功/失败。
- 直接测试用：[按班拆分_60个Excel.zip](按班拆分_60个Excel.zip)（解压后全选 60 个文件上传）。
- 教师同理支持一个学科一个文件，文件名=学科；测试包：[按学科拆分_13个Excel.zip](按学科拆分_13个Excel.zip)。

### 小组 / 任教

**不在 Excel 里输入。** 导入名单后，在网页里设置：

- 班主任、副班主任：班级工作区 → 教师；
- 小组：班级工作区 → 小组；**只有班主任/副班主任可以管理小组**，学科组长等只读查看；
- 任教关系：教师页 / 班级工作区；
- 学科组长可以同时担任班主任/副班主任（教师角色与班级职责分开），兼任后可按班级职责管理小组。

## 学生名单字段

| 列名 | 必填 | 示例 | 说明 |
|---|---|---|---|
| 学号 | 否 | 2026001 | 留空自动生成 `S...`；按学号或“姓名+班级+级”更新 |
| 姓名 | 是 | 张小明 | 学生姓名 |
| 班级 | 是 | 七年级一班 | **年级和班级合并**，不再单独填年级；系统自动建班并归班 |
| 级 | 否 | 2026 | 入学年份，显示为 `2026级`；兼容“届/入学年份”表头 |
| 性别 | 否 | 男 | 只能填 男 或 女 |

按班分 sheet 时，sheet 名就是班级，例如 `七年级一班`；表内可以只写：`学号 / 姓名 / 性别 / 级`。

## 教师名单字段

| 列名 | 必填 | 示例 | 说明 |
|---|---|---|---|
| 工号 | 否 | T001 | 留空从 `T001` 起自动生成；也是登录账号 |
| 姓名 | 是 | 王老师 | 教师姓名 |
| 学科 | 条件必填 | 语文 | 学科组长必填；语数英物化生政史地体音美微 |
| 手机号 | 否 | 13800000001 | 也可作为登录账号 |
| 初始密码 | 否 | 123456 | 留空默认 123456 |
| 角色 | 否 | 任课教师 | 任课教师/学科组长/校长主任；留空默认任课教师 |

按学科分 sheet 时，sheet 名就是学科，例如 `语文`；表内可以只写：`工号 / 姓名 / 手机号 / 初始密码 / 角色`。

## 通用规则

1. 表头按名称识别；旧模板的“入学年份/届”“年级”仍兼容。
2. 按学号/工号幂等去重；学生缺学号按“姓名+班级+级”匹配；错误逐行报告。
3. 教师默认密码 123456；首次登录后请改密。
4. 管理台「一键清除名单」会清除学生、小组、班级、任教关系、非管理员教师、点赞/兑换记录、导入历史；保留学期、奖励目录和管理员账号，需管理员密码并输入“清除名单”确认。
5. `admin` 不属于教师名单；由系统保留，默认密码 `admin123`。
