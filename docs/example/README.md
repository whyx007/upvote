# 名单导入示例

本文件夹是「名单导入」的可直接上传示例，不是必须全部导入。

## 文件说明

| 文件 | 用途 |
|---|---|
| `七年级一班.xlsx` / `七年级二班.xlsx` | 每班一个学生文件；文件名就是班级，文件内只有「学生」sheet |
| `语文.xlsx` / `数学.xlsx` | 每学科一个教师文件；文件名就是学科，文件内只有「教师」sheet |
| `全量学生名单_每年级两班.xlsx` | 一个工作簿、每班一个 sheet；只保留七/八/九年级各两个班 |
| `全量教师名单_语文数学.xlsx` | 一个工作簿、每学科一个 sheet；只保留语文、数学 |

## 学生文件

- 只支持 `.xlsx`
- 每班一个文件时，文件名必须等于班级名，如 `七年级一班.xlsx`
- 文件里只需要：

```text
学号 | 姓名 | 性别
```

- 文件名已经是班级，`班级` 列可以空着；如果填写，必须与文件名一致
- 一次可以多选多个班级文件批量上传

## 教师文件

- 每学科一个文件时，文件名必须等于学科名，如 `语文.xlsx`
- 文件里通常填：

```text
工号 | 姓名 | 手机号 | 初始密码 | 角色
```

- 文件名已经是学科，`学科` 列可以空着；如果填写，必须与文件名一致
- 角色可填：任课教师 / 学科组长 / 校长主任
- 不填初始密码时默认 `123456`

## 导入后

小组、任教关系、班主任/副班主任请在网页设置；然后创建并激活学期，即可开始点赞。
